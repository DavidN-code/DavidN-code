## 🚀 Featured Project

### TeamBoard — Multi-Tenant Project Management SaaS

TeamBoard is a deployed full-stack project management application built to demonstrate production-oriented SaaS architecture and security practices.

**Highlights:**
- Multi-tenant organization architecture with tenant-scoped data access
- Server-enforced role-based access control (Owner, Admin, Member)
- JWT authentication and bcrypt password hashing
- Kanban boards with drag-and-drop task management
- Task assignment, comments, notifications, and invitations
- Real-time collaboration using authenticated Pusher private channels
- Organization activity feed and administrative audit logs
- 32 automated integration and security regression tests
- GitHub Actions continuous integration
- Responsive desktop and mobile interface

**Tech:** React · Vite · Node.js · Express · MongoDB · Mongoose · Pusher · Jest · Supertest
